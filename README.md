# 💛 My Elzero JavaScript Bootcamp Journey & Solutions

Welcome! This repository contains all my completed assignments, challenges, and practical hands-on projects built while taking the **JavaScript BootCamp** course by Osama Elzero (**Elzero Web School**).

---

## 📌 Topics Covered

- [x] **Basics & Fundamentals:** Variables, Data Types, Arithmetic Operators, and Conditionals.
- [x] **Control Flow & Functions:** Switch statements, Loops, Function Scopes, and Arrow Functions.
- [x] **Objects & Data Structures:** Object Literals and Functional Programming methods (`Map`, `Filter`, `Reduce`).
- [x] **DOM & BOM Manipulation:** Interacting with page elements, User Events, and Browser Storage (`LocalStorage`).
- [x] **Object-Oriented Programming (OOP):** Classes, Constructors, Encapsulation, and Inheritance.
- [x] **Asynchronous JavaScript:** Working with Promises, legacy `XMLHttpRequest` (XHR), and modern `Fetch API` with `Async/Await`.
- [x] **ES6+ Modern Features:** Destructuring, Modules, `Set` & `Map`, and Regular Expressions (Regex).
